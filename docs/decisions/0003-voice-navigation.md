# 0003 - Navegación contextual por voz

## Contexto

La app necesita un acceso rápido a comandos o interacción de voz desde el shell principal.

## Decisión

Se implementa activación por long-press desde la bottom nav, con navegación contextual hacia la pantalla de voz.

## Impacto

- acceso rápido y consistente
- integración natural con navegación principal

## Riesgos

- mala calibración del gesto
- confusión si no se da feedback visual suficiente
