# Convenciones Git

## Ramas

- `main`: estable
- `develop`: integración
- `feat/*`
- `fix/*`
- `chore/*`
- `docs/*`

## Commits

Formato recomendado:
- `feat: ...`
- `fix: ...`
- `chore: ...`
- `docs: ...`
- `refactor: ...`
- `test: ...`

## Reglas

1. No subir artefactos locales.
2. No subir archivos temporales de agents o skills locales.
3. Todo cambio estructural importante debe ir acompañado de documentación.
