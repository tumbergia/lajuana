# Convenciones de nombres

## Flutter

- archivos: `snake_case.dart`
- widgets: `PascalCase`
- enums: `PascalCase`
- valores enum: `camelCase`
- extensiones: `<Tipo>X`

## Paquetes

- `mobile_ui`: UI reusable
- `mobile_core`: utilidades base
- `mobile_domain`: dominio y contratos
- `mobile_mocks`: mocks y fixtures

## Nombres prohibidos

- `helpers`
- `utils`
- `misc`
- `common`

Esos nombres no describen responsabilidad.
